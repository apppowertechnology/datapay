Every Service Powered by STRICTWALLET

Here is the verified list of all services currently implemented and available on STRICTWALLET, complete with access methods, requirements, and applicable fees.

Open Free Account View Complete Fee Schedule

1. Mobile Data Purchase

What it does: Dispatches high-speed mobile internet bundles across MTN, Airtel, Glo, and 9mobile via automated telecom gateway integration.

  • How to access: Sign in → Select "Data Bundles" → Select Network & Plan → Enter Phone Number → Confirm with 4-digit PIN.
  • Requirements: Active wallet balance, valid 10+ digit Nigerian mobile number, configured 4-digit Transaction PIN.
  • Fees / Charges: Published selling price of the bundle (no hidden markups).
View Live Data Plans

2. Instant Airtime Top-Up

What it does: Instant electronic airtime recharge to any phone number in Nigeria with 24/7 automated delivery.

  • How to access: Sign in → Select "Airtime Top-Up" → Pick Network & Amount → Confirm with PIN.
  • Requirements: Minimum recharge ₦50, maximum recharge ₦50,000 per transaction; 4-digit Transaction PIN.
  • Fees / Charges: ₦0.00 surcharge (Customer pays exact face value).
Recharge Talk-Time

3. Digital Wallet Funding

What it does: Instantly credits your digital wallet balance via secure card payment, bank transfer, or USSD code through the integrated Paystack gateway.

  • How to access: Dashboard → Click "Fund Wallet" → Enter Amount → Complete Paystack checkout.
  • Requirements: Registered account; minimum deposit amount of ₦100.00.
  • Fees / Charges: Standard payment gateway checkout processing.
Funding Guide

4. Event Creation & Publishing

What it does: Allows organizers to create custom event pages with event flyer banner, ticket artwork, venue, date, time, sales period, and branded SEO slugs.

  • How to access: Sign in → "Events & Tickets" → "Create Event" → Fill form & upload artwork → Publish.
  • Requirements: Registered account, event details, valid promotional artwork (JPG, PNG, WEBP).
  • Fees / Charges: 100% Free to create and publish events.
Learn Event Creation

5. Multi-Tier Ticket Selling

What it does: Organizers can create customized ticket tiers (e.g. Free, Early Bird, Regular, VIP, Table) with individual pricing and seat capacity limits.

  • How to access: Within Event Creator → Add Ticket Tier → Specify Category Name, Price, and Available Quantity.
  • Requirements: At least one configured ticket tier per published event.
  • Fees / Charges: Free tickets: 0% fee. Paid tickets: 3% platform commission retained upon sale.
Ticket Fee Details

6. Ticket Purchasing & E-Passes

What it does: Customers purchase tickets directly using wallet balance. The system generates unique Ticket IDs, anti-counterfeit QR tokens, and downloadable high-res PDF tickets.

  • How to access: Open any event page (e.g. strictwallet.com.ng/event/slug) → Choose Tier → Input Name → Enter PIN.
  • Requirements: Sufficient wallet balance, 4-digit PIN.
  • Fees / Charges: Exact ticket face value (no buyer surcharge).
Ticket Buying Guide

7. Gate Scanner & QR Verification

What it does: Built-in web camera scanner for event entrance check-in. Scans attendee QR codes, validates against backend records, and marks tickets as used to prevent duplicate entry.

  • How to access: Organizer dashboard → Select Event → Click "Gate Scanner" → Allow camera permission → Scan QR codes.
  • Requirements: Event Creator permissions, device with camera (smartphone or tablet).
  • Fees / Charges: 100% Free tool for all event organizers.
Gate Scanner Guide

8. Event Creator Wallet & Analytics

What it does: Segregates event revenue from personal funds. Tracks gross sales, net creator earnings (97%), attendee lists, ticket buyer emails, and payout history in real time.

  • How to access: Event management dashboard → "Creator Wallet" tab.
  • Requirements: Creator must have published at least one event.
  • Fees / Charges: ₦0.00 wallet maintenance fee.
Creator Wallet Details

9. Direct Bank Withdrawals

What it does: Disburses organizer ticket earnings directly to any commercial bank account in Nigeria via Strowallet API with live NUBAN name enquiry verification.

  • How to access: Creator Wallet → "Withdraw Funds" → Select Bank & Account Number → Verify Name → Enter Amount & PIN.
  • Requirements: Valid Nigerian commercial bank account matching creator name, 4-digit PIN, minimum payout balance.
  • Fees / Charges: Flat ₦20 bank transfer fee. Statutory ₦50 stamp duty applies only on withdrawals of ₦10,000 and above (₦0 on withdrawals below ₦10,000). Bank receives 100% of requested principal.
Withdrawal Fee Rules
